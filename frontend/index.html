Core Capabilities

Built for real

Every component is designed around the three things a credit officer actually needs: speed, accuracy, and an explainable reason.

🧠
Four ML Models, One Champion
Logistic Regression, Decision Tree, Random Forest, and XGBoost are trained and compared on the same dataset. The highest-AUC model serves every live prediction automatically.
sklearn · xgboost
📊
Real-Time Risk Scoring
Enter an applicant's profile and receive a default probability in milliseconds, served from a FastAPI backend with the trained model pre-loaded in memory.
FastAPI · Uvicorn
💡
SHAP Explainability
Every prediction ships with a Shapley-based breakdown of feature contributions — showing exactly which factors drove the risk score up or down, in plain language.
SHAP · TreeExplainer
⚖️
Regulatory-Grounded Categories
Probabilities are mapped to Low / Medium / High risk bands using thresholds grounded in Basel III and RBI NPA guidelines, with a concrete lending recommendation for each.
Basel III · RBI guidelines
🔢
Live Financial Ratio Engine
DTI and LTI ratios are computed and colour-coded as you type — letting analysts spot red flags before the model even runs.
DTI · LTI · Feature Eng.
☁️
Production AWS Deployment
Frontend on S3 + CloudFront CDN. Backend on Render.com. Auto-deploys via GitHub Actions CI/CD.
EC2 · S3 · CloudFront
